# 💪 FitLog — Workout Library

## 📋 Short Description
FitLog is a dark, no-nonsense gym companion built with Next.js and Tailwind CSS that lets users pick lifts, lock them into today's plan, and track weekly workout progress.

## 🛠️ Technologies Used
* **Framework:** Next.js (App Router)
* **Styling:** Tailwind CSS
* **Deployment:** Vercel / Netlify

## ✨ Key Features
1. **Responsive Workout Library:** Browse 12 major lifts categorized by muscle groups in a responsive grid layout.
2. **Interactive Workout Details:** View comprehensive stats, equipment requirements, and step-by-step instructions.
3. **Today's Plan & Saved Lifts:** Add up to 5 lifts to today's plan or save them for later with persistent state tracking and toast notifications.
4. **Live Metrics Summary:** Track active exercises, total minutes, and calories burnt in real-time.
5. **Dynamic Filtering & Sorting:** Sort workouts easily by duration, calories, or rating.
